  note: background IoU (0.3868 on 119 crops) is STRUCTURAL, not a comparable failure - a crop is the union of the unit's OWN boxes, so background is only the thin leftover corners and gaps, a small region where IoU is naturally harsh. It is not evidence against the model.
  note: cartridge (122 instances) and bay (36 instances) crop populations are OVERLAPPING on this validation split, measured fresh this run (not assumed): 88 crops carry cartridge only, 2 carry bay only, 34 carry BOTH in the SAME crop, 0 carry neither. See seg_dataset.py's module docstring for why this can no longer be assumed disjoint (real tray-wall geometry, commits a31ac28..043e92d). Either way, 0.9422 and 0.8676 are each pooled independently over their own class's pixels across the whole split - a marginal per-class statistic, not a per-crop joint one - so this is still not evidence the model handles both together within the SAME crop, even on crops where both truly co-occur.
  note: checkpoint selection is noise-limited - best.pt 0.6708 and last.pt 0.6677 differ by 0.0031 on 36/18/19 (bay/electronics/obstruction) val instances, and both ship.

Boundary displacement, mm (mean distance from a predicted boundary pixel to
the nearest ground-truth boundary pixel; the figure that chose a per-ROI
segmenter over a 28x28 Mask R-CNN head). Each crop is converted at ITS OWN
frame's ground sample distance, not at one constant. `head mm` is the SAME
comparison the architecture argument always made, converted the same way:
  class               mm     crops     mm/px   head mm  clears by
  ---------------------------------------------------------------
  bay              3.534        34    0.7765     3.633      1.03x
  electronics      6.379        17    0.7629     3.569      0.56x
  obstruction      2.922        17    0.7670     3.589      1.23x
  ---------------------------------------------------------------
  head mm = 4.68 px x that class's own mean mm/px. The 4.68 x 10.29 px comes from a 28x28 head over a PowerCore26800 crop of ~131 x 288 px (FDR 13.2.1), which is 2.9 x 6.4 mm at the generator's NOMINAL 0.6250 mm/px - the figure the FDR published, and the framing no frame in this corpus was rendered at.
  Both sides of this comparison are pixel counts times the same scale, so the `clears by` ratio is SCALE-INVARIANT: correcting the calibration moves the millimetres and leaves the architecture verdict exactly where it was.
  verdict: NOT below the mask-head quantisation figure for at least one class - the architecture choice in spec 3.1 is NOT supported by this measurement and should be revisited, not defended.
